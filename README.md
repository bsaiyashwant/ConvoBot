# ConvoBot 🤖

ConvoBot is an AI-powered study tool and chat assistant made by and for students. It features a clean, professional interface, persistent textbot through Firebase, and is powered by Google's Gemini 1.5 model.

## 🚀 Live Demo
Check out the live application here: [https://convobotai.vercel.app/](https://convobotai.vercel.app/)

## ✨ Features
- **Sleek UI**
- **Persistent Chat History**: Conversations are securely saved to Firebase Firestore, allowing you to pick up right where you left off.
- **Secure Authentication**: Integrated Email/Password and Google Sign-In.
- **Cross-Platform**: Fully responsive design that works on mobile and desktop.
- **24/7 Availability**
